NBK-E IT Enterprise Monitoring — Onboarding Console

See README.md for the complete project documentation, page list and editing instructions.

Quick start: open index.html in a browser. No build step or package installation is required.

The site has seven pages in English and Arabic: Overview, Access checklist, Systems & portals, ATM Operations, Infrastructure, Personal Services and Frequently Asked.

Edit js/content.js for English and js/content.ar.js for Arabic. Keep keys, IDs, URLs and collection order aligned.

Infrastructure includes 12 teams and their responsibilities in both languages, with search and team selection.

Employee FAQs are ordered by faqPage.items in each content file: the health-insurance limit question is third and the Uber billed to NBK question is fifth.

Progress, language and theme preferences are stored locally per browser/device. The logo is images/nbk-logo.png.

Internal onboarding reference — not for external distribution.
